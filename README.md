# Deteksi Penyakit Buah Kakao Menggunakan CNN  
### Aplikasi Android Berbasis Flutter dan TensorFlow Lite

## 📖 Deskripsi Proyek
Proyek ini merupakan hasil skripsi yang membahas deteksi penyakit pada buah kakao berbasis citra digital menggunakan metode Convolutional Neural Network (CNN).

Model CNN yang telah dilatih diintegrasikan ke dalam aplikasi Android menggunakan Flutter dan TensorFlow Lite, sehingga sistem mampu melakukan deteksi penyakit buah kakao secara real-time melalui perangkat mobile.

Aplikasi ini ditujukan untuk membantu petani atau praktisi pertanian dalam mengidentifikasi penyakit buah kakao secara cepat dan akurat.

---

## 🎯 Tujuan
- Mengembangkan sistem deteksi penyakit buah kakao berbasis citra digital  
- Menerapkan metode CNN untuk klasifikasi penyakit  
- Mengintegrasikan model CNN ke dalam aplikasi Android  
- Menyediakan antarmuka aplikasi yang mudah digunakan  

---

## 🧠 Metodologi
1. Pengumpulan dataset citra buah kakao  
2. Pra-pemrosesan citra (resize, normalisasi)  
3. Pelatihan model CNN  
4. Konversi model ke TensorFlow Lite  
5. Implementasi model ke aplikasi Flutter  

---

## 🛠️ Teknologi yang Digunakan
- Flutter  
- Dart  
- TensorFlow Lite  
- Convolutional Neural Network (CNN)  
- Android
